# Methodology

1. Download historical F1 data using KaggleHub.
2. Load CSV files using Pandas.
3. Validate and clean columns.
4. Merge related tables using raceId, driverId, constructorId and circuitId.
5. Convert pit-stop durations to numerical values.
6. Perform exploratory data analysis.
7. Create Plotly visualizations.
8. Build the Streamlit dashboard.
9. Interpret trends and document findings.
