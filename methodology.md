# Methodology

1. Download historical F1 data using KaggleHub.
2. Load CSV files using Pandas.
3. Clean and validate columns and values.
4. Merge datasets using relational IDs.
5. Calculate pit-stop statistics.
6. Perform exploratory data analysis.
7. Create Plotly visualizations.
8. Present results through Streamlit.
9. Interpret trends and produce insights.
